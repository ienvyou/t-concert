# 응답 수집 설정 (5분)

지인들의 응답이 내 Google 스프레드시트에 자동으로 쌓이게 하는 설정입니다.
전부 내 Google 계정 안에서만 돌아가고, 외부 서비스는 쓰지 않습니다.

## 1. 스프레드시트 만들기
1. https://sheets.new 접속 → 빈 시트가 생깁니다.
2. 이름을 `나를 발견하기 응답` 정도로 바꿉니다.

## 2. 스크립트 붙여넣기
1. 시트 상단 메뉴 **확장 프로그램 → Apps Script**.
2. 기본으로 들어있는 `function myFunction() {}` 를 **전부 지우고**,
   같은 폴더의 `Code.gs` 내용을 **통째로 붙여넣습니다**.
3. 위쪽 `NOTIFY_EMAIL` 값에 내 메일 주소를 넣으면, 응답이 올 때마다 메일 알림이 옵니다.
   (예: `var NOTIFY_EMAIL = '내주소@gmail.com';` — 알림이 필요 없으면 그대로 비워두세요.)
4. 💾 저장.

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴 ⚙️ → **웹 앱** 선택.
3. 설정:
   - 설명: `inspire v1`
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**  ← 이게 제일 중요합니다
4. **배포** 클릭 → 권한 승인 화면이 뜹니다.
   - "Google에서 확인하지 않은 앱" 경고가 나오면
     **고급 → (프로젝트 이름)(으)로 이동 → 허용**.
5. 배포가 끝나면 나오는 **웹 앱 URL** 을 복사합니다.
   `https://script.google.com/macros/s/AKfy....../exec` 형태입니다.

## 4. 사이트에 연결
`index.html` 맨 아래 `<script>` 안, 세 번째 줄을 고칩니다.

```js
var ENDPOINT = "https://script.google.com/macros/s/AKfy....../exec";
```

저장하고 다시 배포하면 끝입니다.
(이 URL만 알려주시면 제가 넣고 배포까지 해드립니다.)

## 5. 확인
1. 복사한 `/exec` URL을 브라우저 주소창에 그대로 붙여넣어 보세요.
   `{"ok":true,"service":"inspire",...}` 가 보이면 정상입니다.
2. 사이트에서 테스트로 한 번 제출해 보고, 시트에 줄이 추가되는지 확인합니다.
3. 테스트 줄은 시트에서 지우면 됩니다.

## 나중에 스크립트를 고쳤다면
**배포 → 배포 관리 → 연필 ✏️ → 버전: 새 버전 → 배포**
를 해야 반영됩니다. URL은 그대로 유지됩니다.

## 문제가 생기면
- **시트에 아무것도 안 쌓인다** → 3번의 "액세스 권한이 있는 사용자"가 `모든 사용자`인지 확인.
- **응답자 화면에 "자동 전송이 되지 않았습니다"가 뜬다** → 응답자는 복사해서 보내주면 되고,
  데이터는 잃지 않습니다. URL과 배포 설정을 다시 확인하세요.
