# 나를 발견하기 — 당신이 본 나

지인 3~5명에게 링크를 보내 나에 대한 피드백을 받는 한 페이지짜리 설문 사이트.
동국대 과정 과제 "1) 나를 발견하기: 강점, 가치, 그림자와 레드버튼" 용.

## 질문 네 가지
1. **강점** — 내가 남들보다 잘하는 것, 잘 풀리는 비결
2. **동기 스위치** — 에너지가 켜질 때 / 꺼질 때 (두 칸)
3. **레드버튼** — 언제 발끈하는지
4. **그림자** — 주위를 힘들게 하는 것, 고치면 좋을 것

공개 주소: **https://t-concert.neoax.kr/inspire/**
(이미 연결돼 있는 t-concert 도메인의 하위 경로라 DNS 설정이 따로 필요 없습니다.
`/slides/` 의 강연 덱·대본과는 서로 영향을 주지 않습니다.)

## 구성
- `index.html` — 사이트 전부 (외부 의존성은 Google Fonts뿐)
- `apps-script/Code.gs` — 응답을 Google 스프레드시트에 쌓는 백엔드
- `apps-script/SETUP.md` — 백엔드 설치 방법 (5분)

## 설정할 곳
`index.html` 아래쪽 `<script>` 시작 부분 두 줄이 전부입니다.

```js
var ENDPOINT = "";   // Apps Script 웹앱 /exec URL. 비어 있으면 '복사해서 보내기'로 동작
var OWNER    = "";   // 페이지에 표시할 이름. 비어 있으면 이름 없이 1인칭
```

## 동작 메모
- `ENDPOINT` 가 비어 있거나 전송이 실패하면, 응답자에게 정리된 텍스트와 복사 버튼을 보여줍니다.
  어떤 경우에도 응답자가 쓴 글이 사라지지 않습니다.
- 작성 중인 내용은 응답자 브라우저의 localStorage에 임시 저장돼, 실수로 닫아도 이어서 쓸 수 있습니다.
- 응답자 이름과 관계는 선택 입력입니다.
